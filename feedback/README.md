# 问题反馈

用插件时遇到问题,或者有什么想说的,都可以提。

## 用 issue 反馈(推荐)

到本仓库的 **Issues** 里开一条,模板会自动问你该填什么。反馈会被
「Star OS 插件工具」的**反馈页**直接拉取、回复、关闭,所以请用 issue 提。

开 issue 时请尽量带上:

- **插件名 / id**(例如 `com.staros.dailytip`)
- **插件版本**(在「插件中心 → 已安装」里能看到)
- **模块版本**(Star OS 应用首页就有,例如 1.5)
- **你勾了哪些权限**
- **现象**:做了什么 → 期望什么 → 实际什么
- **日志**:插件中心 → 已安装 → 日志,把内容贴上来(这一步最关键)

## 反馈标签

| 标签 | 用途 |
|---|---|
| `feedback/bug` | 插件跑不起来、报错、行为不对 |
| `feedback/idea` | 想要的功能、改进建议 |
| `feedback/security` | 安全问题(比如某个插件权限要得过分) |
| `feedback/other` | 其它 |

## 安全相关

如果你发现某个插件**申请了与功能不相称的权限**,或者源码里有可疑动作:

- 开一条 `feedback/security` issue;
- 或者直接联系维护者。

源码都在 `plugins/<id>/` 里公开着,欢迎任何人复查。
一旦确认有问题,插件会被**立即下架**(从 `index.json` 里移除)。

## 提插件的问题 vs 提模块的问题

- **插件本身的问题**(某个插件跑不通、权限不对)→ 提到本仓库;
- **模块的问题**(开机动画、字体、图标、模块更新)→ 提到
  [star-os-assets](https://github.com/lqbz6office/star-os-assets) 或通过应用内公告渠道反馈。
