# 亮度助手

三档亮度一键切换,并且**记住你选的那一档** —— 重启后自动恢复。

## 它做什么

- **手动运行**:在「暗 → 中 → 亮 → 暗」之间轮换,当场生效,并弹一条通知告诉你切到了哪档;
- **每次开机**:自动把亮度恢复成你上次选的那档。**如果从没手动选过,开机就完全不碰亮度**,不会自作主张。

三个档位对应的亮度值写在脚本开头,觉得不合适直接改数字:

| 档位 | 亮度值(0-255) |
|---|---|
| 暗 | 30 |
| 中 | 110 |
| 亮 | 200 |

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `settings.read` | 读当前亮度值 —— 用来显示,也用来确认到底改成功没有 |
| `settings.write` | 真正把亮度值写进系统设置 |

两个都是**中风险**权限,安装时不会自动勾选,需要你在授权页手动勾上。
不勾也能装、能跑,但运行时会提示改亮度没成功(不会报错崩掉)。

## 数据存在哪

`$SOS_DATA/mode` —— 就一行字,记的是上次选的档位(`dark` / `mid` / `bright`)。
删掉它,插件就退回「从没选过」的状态。

## 触发时机

- `boot` —— 每次开机恢复档位
- `manual` —— 在应用里点「运行」切换档位

## 代码看点

- **改完要读回来验一遍**:写入类操作在很多机型上会静默失败,
  所以这里写完立刻读一次确认,而不是写完就当成功;
- **顺手关掉系统自动亮度**:自动亮度开着的时候,手写的值会被系统很快改回去,
  所以先把它关掉再写值;
- **没选过就不动手**:开机钩子里先判断有没有档位记录,
  没有就直接退出 —— 插件不该在用户没要求的时候改用户的设置。
