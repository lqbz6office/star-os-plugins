# 开机信息提醒插件

## 功能说明

开机时自动弹出系统通知，实时显示设备状态：

- **日期**：当前年月日 + 星期
- **时间**：当前时分秒
- **电量**：电池剩余百分比
- **WiFi**：当前连接的无线网络名称（未连接时显示「未连接」）
- **媒体音量**：当前媒体流音量值
- **铃声音量**：当前铃声流音量值

## 使用的权限

| 权限 | 风险等级 | 用途 |
|---|---|---|
| notify | 低 | 弹出系统通知展示信息 |
| settings.read | 中 | 读取系统音量设置（volume_music / volume_ring） |

## 数据存储

本插件**不存储任何用户数据**。每次运行时实时读取系统状态并通过通知展示，运行结束后不保留任何信息，也不联网上传。

## 触发时机

| 钩子 | 说明 |
|---|---|
| boot | 每次开机后自动运行（系统启动完成 + 15 秒缓冲后） |
| manual | 可在插件中心手动点击运行，随时查看当前设备状态 |

## 信息获取方式

| 信息 | 获取方式 | 是否需要权限 |
|---|---|---|
| 日期/时间 | `date` 命令 | 否 |
| 电量 | 读取 `/sys/class/power_supply/battery/capacity` | 否 |
| WiFi 名称 | `dumpsys wifi` 解析 SSID 字段 | 否 |
| 音量 | `sos-settings-get system volume_music / volume_ring` | 是（settings.read） |
| 通知展示 | `sos-notify` | 是（notify） |

## 注意事项

- WiFi 名称通过系统 `dumpsys` 接口读取，若 WiFi 未连接或刚开机尚未连接，显示「未连接」
- 电量读取自系统电池设备节点，极少数设备若无该节点则显示「未知」
- 音量值为 Android 系统原始整数值，不同设备的最大音量档位可能不同
- 开机钩子为并发执行，不阻塞开机流程
