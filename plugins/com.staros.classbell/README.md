# 课程提醒

一份自己的课程表,开机自动提醒下一节课。

## 它做什么

- **安装完**会先把内置的示例课程表复制一份到插件数据目录,方便你改;
- **每次开机**检查:距离下一节课 **15 分钟以内**就弹通知提醒;
- **手动运行**打印今天全部课程 + 下一节课还有多久上课。

## 课程表怎么写

装好之后编辑这个文件(在插件的可写数据目录里):

```
/data/adb/star_os/plugins/com.staros.classbell/data/plan.txt
```

一行一节课,三段,用空格分开:

```
周一 08:00 语文
周一 08:50 数学
周二 08:00 英语
```

| 段 | 说明 |
|---|---|
| 星期 | `周一` 到 `周日`,写中文,别写「星期一」 |
| 时间 | 24 小时制,`HH:MM`,例如 `08:00`、`14:30` |
| 课程 | 一个词,中间别加空格 |

`#` 开头的行是注释,空行会被忽略。想加周三的课就自己补一行,改完保存,**下次开机生效**。

> 提示:文件里的中文按 UTF-8 存,用记事本改的话记得别存成别的编码。

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `notify` | 弹上课提醒(`sos-notify`) |

**低风险**权限,安装时默认勾选。只能弹提示。

## 数据存在哪

`$SOS_DATA/plan.txt` —— 你的课程表。**升级插件不会丢掉它**,放心改。

如果数据目录不可写(极少见),插件会自动改用内置的那份课程表,不会直接罢工。

## 触发时机

- `install` —— 安装完后复制一份课程表模板
- `boot` —— 每次开机检查是否快到上课时间
- `manual` —— 在应用里点「运行」看今天的课

## 代码看点

- **前导零的坑**:`date '+%H'` 给出的可能是 `08`,
  在 shell 里 `$((08))` 会被当八进制解析而报错 ——
  所以这里先用 `sed` 把开头的零去掉再参与运算。这是 shell 计时的经典陷阱;
- **两份课程表**:优先读可写的那份,没有就用内置的。
  这样「用户改过」和「刚装还没改过」两种情况都能正常工作;
- **只在快上课时提醒**:开机钩子里判断距离,超过 15 分钟就安静待着,
  不会一天到晚弹通知。
