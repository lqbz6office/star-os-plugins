# 每日一句

每次开机弹一条随机小贴士。

## 它做什么

开机时(或你在应用里手动点「运行」)从 `res/tips.txt` 里随机抽一行,
用系统通知弹出来。

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `notify` | 弹一条系统通知(`sos-notify`) |

这是**低风险**权限,安装时默认就勾上了。它只能弹提示,碰不到系统任何东西。

## 数据存在哪

不存数据。

## 触发时机

- `boot` —— 每次开机(系统启动完成 + 15 秒缓冲后)
- `manual` —— 在应用里点「运行」

## 怎么改内容

改 `res/tips.txt`,一行一条。想看效果直接手动运行一次。

## 代码看点

- **怎么读自己的资源文件**:用 `$SOS_SRC`(只读目录),
  不是 `$SOS_DATA`(可写目录)。写反了会读不到;
- **怎么取随机数**:busybox ash 不保证有 `$RANDOM`,
  这里用 `date '+%s'` 取秒数取模,简单且够用;
- **先用 `-$TOTAL` 判断再算**:`wc -l` 读不到时会返回空字符串,
  直接参与算术运算会报错 —— 对空值先兜底是 shell 脚本的基本修养。
