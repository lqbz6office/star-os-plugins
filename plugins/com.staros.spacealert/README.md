# 空间哨兵

盯着手表的存储空间,快满了提前告诉你。

## 它做什么

- **每次开机**检查 `/data` 分区剩余空间:
  - 少于 **1GB** → 弹一条「建议清理」;
  - 少于 **300MB** → 弹一条「请尽快清理」的严重告警;
- **手动运行**打印完整报告:总量、已用、剩余、使用率,外加一个结论和一些清理提示。

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `notify` | 弹告警(`sos-notify`) |

**低风险**权限,安装时默认勾选。只能弹提示,碰不到系统任何东西。

## 数据存在哪

不存数据,每次都是现查现报。

## 触发时机

- `boot` —— 每次开机
- `manual` —— 在应用里点「运行」

空间够用的时候是安静的,不弹通知。

## 想改阈值

改 `main.sh` 开头两行:

```sh
SP_WARN_MB=1024    # 低于这个数(MB)提醒
SP_CRIT_MB=300     # 低于这个数(MB)严重告警
```

## 代码看点

- **不用 awk**:很多 Android 设备上根本没有 awk,
  所以这里用 shell 的 `for` 把一个命令行分词,再按列号取值;
- **列号是靠顺序定的**:`df` 的标准列序是固定的(文件系统 / 总量 / 已用 / 可用 / 使用率 / 挂载点),
  取第 4 列就是可用空间;
- **算不出结果就别硬算**:可用空间那列如果不是纯数字,直接判定「解析失败」并说明,
  而不是拿一个空字符串去做算术运算。
