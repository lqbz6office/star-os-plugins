# 电量守护

盯着手表的电量:快没电了提醒你充,充满了提醒你拔。

## 它做什么

- **每次开机**检查一次电量:低于 20% 弹一条「记得充电」,充电时到 95% 以上弹一条「可以拔了」;
- **手动运行**(插件中心 → 已安装 → 运行)会打印一份完整报告:当前电量、充电状态、电池温度,以及最近 5 次记录。

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `notify` | 弹提醒(`sos-notify`) |

这是**低风险**权限,安装时默认就勾上了。它只能弹提示,碰不到系统任何东西。

## 数据存在哪

`$SOS_DATA/battery.log`(插件自己的数据目录),每次运行追加一行,只保留最近 100 行。
删掉这个文件不影响使用,只是历史记录清空。

## 触发时机

- `boot` —— 每次开机(系统启动完成 + 15 秒缓冲后)
- `manual` —— 在应用里点「运行」

开机时**只在需要提醒的时候**才弹通知,平时是安静的,不会每天开机都打扰你。

## 想改阈值

打开 `main.sh`,改最上面三行:

```sh
BG_LOW=20        # 低于这个百分比提醒充电
BG_FULL=95       # 充电时超过这个百分比提醒拔掉
BG_KEEP=100      # 日志保留行数
```

## 代码看点

- **电量是纯读文件拿的**:`/sys/class/power_supply/*/capacity`,属于「只查看、改不动任何东西」,
  不需要任何权限。这类节点在不同机型上名字不一样,所以脚本会挨个试;
- **温度有单位坑**:多数机型给的是 0.1 度(320 = 32.0 度),少数直接给度,
  脚本用「值大于 200 就按 0.1 度算」区分;
- **日志不会无限长**:每次写完检查行数,超过上限就只留最后 N 行。
