# 你好插件

Star OS 插件的**最小可用示例**——用来确认插件系统通了没有,也是学写插件的起点。

## 它做什么

打开 Star OS 应用 → 插件中心 → 已安装 → 点「运行」,它会打印:

- 自己的插件 id、触发钩子
- 插件 API 版本
- 当前拿到的权限
- 自己的数据目录 / 工作目录

同时往自己的数据目录写一行日志,并告诉你累计运行了多少次。

**它不改系统的任何东西**,所以不需要任何权限。

## 用了哪些权限

无。

## 数据存在哪

```
/data/adb/star_os/plugins/com.staros.hello/data/hello.log
```

卸载插件时这个目录会一起删掉。

## 触发时机

- `install` —— 装好后立刻跑一次
- `manual` —— 在应用里点「运行」

## 代码看点

- `$SOS_ID` / `$SOS_HOOK` / `$SOS_DATA` 是执行器注入的环境变量;
- `sos-id` / `sos-api` / `sos-perms` 是注入的包装命令(不需要权限);
- 插件**唯一被保证可写**的地方就是自己的 `$SOS_DATA`;
- 想读文件 / 联网 / 改设置,都要先声明对应权限,并且用 `sos-*` 包装命令,
  别直接调系统命令(直接调会被审核拒绝,示例见 `com.staros.sysinfo`)。
