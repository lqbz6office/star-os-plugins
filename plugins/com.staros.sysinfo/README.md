# 系统信息

一个**只读**插件:手动运行,把设备的关键信息列出来。

## 它做什么

打开 Star OS 应用 → 插件中心 → 已安装 → 点「运行」,会显示:

- 机型、Android 版本、SDK 版本
- 模块的系统属性 `ro.product.careme.version`
- 开机时长
- 内存占用(前几行 `/proc/meminfo`)
- `/data` 分区剩余空间

## 用了哪些权限

| 权限 | 为什么需要 |
|---|---|
| `settings.read` | 读系统属性(`sos-getprop`)。这个权限只读,不能改任何设置。 |

安装时会弹出授权页,只勾选 `settings.read` 就能用。

## 数据存在哪

不存数据,纯输出。

## 触发时机

- `manual` —— 在应用里点「运行」

## 代码看点

- **只读权限也走包装命令**:用 `sos-getprop` 而不是直接 `getprop`。
  直接调 `getprop` 会在审核阶段被拒(提示「没有声明 settings.read」)——
  因为审核没法保证你只读不写,统一走包装命令才管得住。
- `/proc`、`df` 这类纯查看命令不需要权限,可以直接用。
