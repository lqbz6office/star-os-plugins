# 敖丙星空主题

给 Star OS 手表换一套主题:**星轨表盘 + 星空壁纸 + Star OS 图标包(214 个应用图标)**。

- **作者**:星
- **需要模块**:Star OS 1.5 及以上;建议同时装有 **主题模块(ThemePro)**(否则文件放好了也不生效)
- **适用机型**:4100(SDK 27 / Android 8.1)

## 它做了什么

1. 从云端取一份**主题包**(约 14 MB,4 个镜像轮流试,下完 **校验 sha256**,对不上直接丢弃);
2. 先把原来那套 `aobing` 主题**备份**到插件自己的数据目录;
3. 解压注入到主题模块的目录:
   `/sdcard/Android/baiyao105/ThemePro/Themes/`
4. 弹一条提示,然后你去「个性主题」里选 **敖丙**,表盘列表里选**星轨**那款。

注入的内容:

| 内容 | 说明 |
|---|---|
| 表盘 | 星轨背景 + 浅色数字 + 原版指针(无角色版) |
| 壁纸 | 银河流星(416×468) |
| 图标包 | Star OS 的 214 个应用图标 + 9 个 Activity 图标,桌面文字改白色 |

## 用了哪些权限

| 权限 | 风险 | 为什么必须 |
|---|---|---|
| `shell` | 🔴 高 | Android 8.1 没有 `unzip`,要用 Magisk 自带的 busybox 解压(只有 root 读得到);写内部存储也需要 root 才稳 |
| `network` | 🟡 中 | 从 GitHub 取主题包(4 个镜像轮流试) |
| `notify` | 🟢 低 | 下载/注入过程提示 —— 手表屏幕小,不弹提示会以为程序卡死 |

**`shell` 是红色高风险项,默认不勾**。不勾的话插件装得上,但运行时会告诉你「缺 shell 权限」并停下,什么都不改。

## 数据存在哪

```
/data/adb/star_os/plugins/com.staros.theme.aobing/data/
├── payload.zip      下载的主题包(sha256 对得上才会用)
├── backup/latest/   注入前的原主题(卸载时用来还原)
└── applied.conf     注入时间记录
```

它只往两个地方写东西:**自己的 data 目录**和 **ThemePro 的主题目录**。
不碰系统分区、不装模块、不改任何系统设置。

## 为什么不把主题包直接放进插件里

插件包上限 1 MB / 200 个文件,而且**禁止携带任何二进制**(`.apk`/`.dex`/`.so` 都不行)。
主题包本身 14 MB、253 个文件,里面的表盘 `.cl` 实际上是个 APK —— 塞不进来,也不该塞。
所以走「云端取包 + 本地注入」:插件本体是纯文本脚本,任何人可以逐行看完再决定装不装。

## 怎么卸载 / 还原

在插件中心卸载即会**自动还原**成安装前的主题(用的是备份)。
也可以手动跑一次还原 —— 以 root 身份执行:

```sh
sh /data/adb/modules/zz_star_os/plugin_exec.sh run com.staros.theme.aobing uninstall
```

没有备份记录时(比如从没成功注入过),卸载**不会删任何主题文件**,免得误删你自己下载的主题。

## 常见问题

**Q:运行一次要多久?**
第一次要下 14 MB(建议连着 WiFi),下完之后重跑会跳过下载,秒级完成。

**Q:提示「缺 shell 权限」?**
插件中心 → 已安装 → 敖丙星空主题 → 权限,把红色那项 `shell` 勾上,再点「运行」。

**Q:注入完了但主题列表里没有?**
重启一次手表,或者在「个性主题」里下拉刷新一次。

**Q:想换回原来的主题?**
卸载插件即可自动还原;或者自己去「个性主题」里选回原来那套。
